# V1 产品范围
基线：2026-10-05。先学习自己的直播，后续加入其他主播。第一版单客户、单默认工作区、管理员使用，关闭公开注册；不声称有多客户 SaaS 隔离。

## 闭环
管理主播/场次 → 上传录像或逐字稿 → 转写与抽样画面分析 → 可定位证据 → 单场/周总结 → 话术候选人工审核 → 学习库 → 下一场备播。
PDF 区分参考资料与历史报告，不自动作为主播原话证据。原话、教学解析、适配稿独立保存。
评分入口保留，维度/权重/证据标准未定时不输出正式分；长期画像后续做。

## 页面映射
| 当前路由 | 后端交付 |
|---|---|
| / | 真实任务、待审核、最近场次 |
| /sessions、/sessions/:id | 场次、文件、任务、原文、证据定位 |
| /reports | 单场/周报告、修订、审核、导出 |
| /weekly | 同主播自然周汇总与来源版本 |
| /reviews | 候选修订、批准/拒绝/撤回、版本冲突 |
| /library | 已审核资产、检索、收藏、来源 |
| /plans、/plans/:id | 备播、排序、固定资产引用和适配稿 |
| /settings | 模型状态与允许配置，不回传密钥 |

## 验收
真实录像入库→重启仍可读→完整转写→报告跳到真实证据→审核两条资产→刷新后可检索→备播保存→撤回后历史引用提示。
同主播多场汇总周报，列出来源版本和未分析/失败场次，不把缺失当完成。重新分析不覆盖人工修订。
样例/预处理/真实处理明确区分，无时间戳不编造定位。缺证据的结论标注推测。

## 延后
M5 抖音/视频号采集；实时场控、弹幕/订单/成交归因、多租户、长期画像、向量库/知识图谱不进 V1。
评分标准由用户后续确认；真实样本和账号在 M2 验收前提供，不阻塞基础开发。
