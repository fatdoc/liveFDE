## 暂定结构

1. 报告总览：本场／本周最值得关注的结论，统计范围与版本。
2. 亮点与原话依据：原话与解释分开，支持回看。
3. 问题与待核实项：说明是否已有足够依据，不把猜测写成事实。
4. 表达与节奏观察：暂保留未分析状态，之后确认统计口径。
5. 可学习的话术：只纳入已审核资产，原话、教学说明、适配示例分别呈现。
6. 下一场行动：负责人、执行时点、核验方式，进入备播草稿。
7. 来源与说明：场次、日期、主播、示例与分析边界。

## 原型行为

- 单场报告及主播日期范围汇总（默认周报）。
- 修改六个内容字段；按报告范围单独保存于会话状态。
- 章节开关；总览与来源为必选。
- 版本修订、人工确认；内容、模板或来源数据变化后需要重新确认。
- 行动带入新备播草稿，不越过资产审核。
- Markdown 正文预览、复制与下载入口，浏览器打印入口。
- 仍无真实 AI、数据库、评分规则与持久保存；刷新清空原型修改。
