# 直播复盘资产工作台 · React 交互原型

本轮范围：复刻四张设计图，并按同一风格补齐全部导航页面与主要业务交互。

预览：http://127.0.0.1:5188/

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` | 工作台、周次与主播筛选、下一步待办 |
| `/sessions` | 直播列表、搜索、主播与进度筛选、新建场次 |
| `/sessions/:id` | 材料登记、示例时间轴、逐字稿、复盘报告、评分待配置、候选审核 |
| `/weekly` | 主播周总结、来源场次、行动备注、文本导出 |
| `/reviews` | 待审核／已入库／不入库队列、编辑、批准、驳回、重新审核 |
| `/library` | 场景分类、搜索、收藏、学习标记、来源回看、加入备播 |
| `/plans` | 备播列表、状态筛选、新建计划 |
| `/plans/:id` | 环节排序、富文本稿件、引用资产、预览、确认、文本导出 |
| `/settings` | 工作区、评分待确认、演示说明、重置 |

## 运行

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5188 --strictPort
npm run build
```

React + TypeScript + Vite；组件与页面位于 `src/components`、`src/pages`，示例数据及状态分别位于 `src/data.ts`、`src/store.tsx`。使用 Tiptap 富文本、Radix 弹窗及 dnd-kit 排序。

## 演示边界

- 当前是前端交互原型，未连接 Python、PostgreSQL 或 AI 模型，不依赖 CPB 服务。
- 数据为预设示例，修改保存在内存，刷新或重置后恢复。不要在此存放正式稿件。
- 本地材料只登记文件名；本地视频可预览，不会上传、转写或分析。需要主动点击“使用示例材料体验复盘”才显示预设结果。
- 示例人物图片为生成素材，播放控件模拟时间轴；不是真实直播录像。
- 评分维度、权重与证据规则仍待确认，不输出虚构评分。
- 周总结和复盘正文为演示内容；导出为 TXT，不是正式报告生成服务。
- 参考图：`../../../design/ui-prototype-20261003`。验证记录见 `design-qa.md`，历史截图见工作区 `runtime/prototype-qa-20261005/qa/`。

## 总结报告（新增）

入口 `/reports`，也可从单场详情或主播周总结进入。支持单场／周报、日期范围、正文编辑、章节开关、版本确认、原话回看、行动带入备播。导出先预览 Markdown 正文，可复制或下载；打印使用浏览器对话框。模板依据与待定事项见 `docs/summary-report-template.md`。该模板不是评分标准。
